# 연구 글의 관용 표현과 표기

`term-policy.md`가 용어를 다룬다면, 이 문서는 문장 차원의 관습을 다룹니다. 여기 있는 항목들은 규칙을 기계적으로 밀어붙이면 오히려 어색해지는 자리입니다.

---

## 논문체 관용 표현

### `본 연구`와 `이 연구`

국내 학술 글쓰기 지침은 1인칭 서술을 줄이고, 자신을 가리켜야 할 때 `필자는` 대신 `본 연구는`을 쓰도록 권합니다. 그래서 `본 연구`, `본 논문`, `본 절`은 논문 형식의 글에서 정착된 표현이고, 격식 한자어라고 깎아낼 대상이 아닙니다.

다만 글의 종류에 따라 자연스러운 쪽이 갈립니다.

| 글 | 자연스러운 표현 |
|---|---|
| 논문, 보고서, 제안서 | 본 연구는, 본 논문에서는 |
| 실험 노트, 분석 메모 | 이 실험에서는, 이번 실험은 |
| 기술 블로그, 동료에게 하는 설명 | 주어를 생략하거나 "이번에는" |

### 1인칭

한국어 연구 글은 주어를 생략하는 쪽이 자연스럽습니다. 영어의 *we*를 그대로 옮긴 `우리는`이 문장마다 붙으면 번역투로 읽힙니다.

```
✗ 우리는 세 가지 설정을 비교했다. 우리는 그중 두 번째가 가장 좋았음을 확인했다.
✓ 설정 세 가지를 비교했다. 두 번째가 가장 좋았다.
```

### 피동

학술 정형 표현과 영어식 피동을 갈라야 합니다. 국내 학술 글쓰기 논의에서도 영어의 영향으로 피동이 남용된다는 지적이 반복됩니다.

| 그대로 두는 피동 | 능동으로 고치는 피동 |
|---|---|
| "이 효과는 작업 기억 용량에 의해 매개된다" | "저자들에 의해 제안된 방법" → "저자들이 제안한 방법" |
| "~로 알려져 있다" | "연구팀에 의해 개발되었다" → "연구팀이 개발했다" |
| "~로 정의된다" | "데이터에 의해 학습되었다" → "데이터로 학습시켰다" |

왼쪽은 행위자가 정말 중요하지 않거나 정형화된 서술입니다. 오른쪽은 행위자가 문장 안에 이미 있는데도 피동으로 뒤집은 경우입니다.

이중 피동(`분석되어진다`, `보여진다`)은 어느 쪽에도 속하지 않습니다. 한국어 규범에서 비문으로 보므로 항상 고칩니다.

### 시제

- 한 일은 과거로 씁니다. "세 가지 설정을 비교했다."
- 늘 성립하는 사실은 현재로 씁니다. "attention은 각 token이 다른 token을 얼마나 참고할지 정한다."
- 영어의 현재완료를 `~해 왔다`로 옮기지 않습니다. "여러 연구가 이 문제를 다뤄 왔다" → "여러 연구가 이 문제를 다뤘다."

## 수치와 단위

### `%`와 `%p`

둘을 바꿔 쓰면 사실이 달라집니다. 국립국어원은 `퍼센트`를 기존 수량 대비 증가 비율로, `퍼센트포인트`를 백분율 수치 자체의 차이로 구분합니다.

정확도가 70%에서 72%로 올랐다면,

- **2%p 상승** — 백분율 수치의 차이
- **약 2.9% 증가** — 상대 증가율 (2 ÷ 70)

둘 다 맞지만 다른 말입니다. 원문이 어느 쪽인지 확인하고, 확인되지 않으면 원문 표현을 그대로 둡니다.

### 표기

- 숫자와 `%` 사이는 붙입니다: `2.1%`
- 소수점은 마침표입니다: `0.85`
- 유효숫자는 원문을 따릅니다. 임의로 반올림하지 않습니다.
- 큰 수는 읽기 쉽게 끊습니다: `1,200만 개`, `7B`

### 비교

"향상되었다"보다 수치가 낫습니다. 다만 **원문에 수치가 있을 때만입니다.**

```
원문에 수치가 있음:  정확도가 baseline보다 2.1%p 높았다.
원문에 수치가 없음:  정확도가 baseline보다 높았다.
지어내면 안 됨:     정확도가 baseline보다 2.1%p 높았다. ← 원문에 없던 숫자
```

### 수식과 기호

수식 기호에도 받침 기준으로 조사를 붙입니다.

```
학습률 α를 3e-4로 뒀다
batch size B가 커지면 gradient noise가 줄어든다
$x$가 커질수록
```

## 인용과 참조

### 선행 연구

| 형식 | 예 |
|---|---|
| 번호 인용 | "[12]는 이 문제를 다르게 풀었다" |
| 저자 인용 | "Vaswani 등(2017)이 제안한 구조" |
| 저자 이름 표기 | 원어 그대로. `바스와니`로 음차하지 않습니다 |

`등`은 한국어 논문에서 *et al.*에 대응하는 표준 표현입니다. `외`도 쓰입니다. 한 문서에서 하나로 고정합니다.

### 그림과 표

한국어 문장에는 한국어 명칭을 씁니다.

```
✗ Figure 1에서 보듯이, Table 2에 정리했다
✓ 그림 1에서 보듯이, 표 2에 정리했다
```

캡션 자체가 영문인 문서(영문 논문의 그림을 그대로 가져온 경우)라면 캡션은 원문을 두고 본문에서 "그림 1(Figure 1)"처럼 첫 등장만 병기합니다.

### 코드 식별자

백틱으로 감싸고 조사는 백틱 밖에 붙입니다.

```
`AdamW`를 썼다
`model.generate()`가 반환하는 값
`config.yaml`에서 바꾼다
```
